# Changelog

All notable changes to the **MyStore** Android app will be documented here.

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)  
Versioning follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.5.0] — 2025-11-07

### ✨ Added
- **Live Delivery Tracking** — Watch your order move on a real-time map
- **Force Update System** — Auto-prompt when a critical update is available
- **PDF Invoice Download** — Save/share bills directly from order details

### 🎨 Improved
- Redesigned deals carousel with warmer gradient cards
- Smoother pull-to-refresh animation
- Better shimmer skeleton loading

### 🐛 Fixed
- Cart total mismatch on rapid quantity changes
- Wishlist heart icon not updating on product detail
- Crash on order history with very old orders

---

## [2.4.0] — 2025-10-18

### ✨ Added
- **PDF invoice** generation from Order Detail screen
- **Dark mode** support across all screens

### 🎨 Improved
- Updated product card UI with better spacing
- Faster image loading with Coil cache tuning

### 🐛 Fixed
- Login screen keyboard overlapping password field
- Search suggestions flickering on slow networks

---

## [2.3.0] — 2025-09-12

### ✨ Added
- Brand new **home screen** with categories, deals, and popular products
- **Wishlist** persistence across sessions
- **Service strip** with trust indicators

### 🐛 Fixed
- Splash screen stuck on cold start (Android 14)
- Category grid misalignment on tablets

---

## [2.0.0] — 2025-07-01

### 🚀 Major Release
- Complete **Jetpack Compose** migration
- Material 3 design system
- New navigation architecture with type-safe routes
- Firebase Auth (email + phone)

---

## [1.0.0] — 2025-05-15

### 🎉 Initial Release
- Product catalog & categories
- Cart & checkout
- Order placement and history
- Basic profile management
