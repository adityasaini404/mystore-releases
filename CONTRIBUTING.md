# Contributing to MyStore Releases

Thanks for your interest! This repository is **release-only** — it does not contain source code. Here's how you can help:

---

## 🐛 Reporting Bugs

1. **Search first** — check [existing issues](../../issues) to avoid duplicates
2. **Use the template** — click [**New Issue**](../../issues/new?template=bug_report.yml)
3. **Be specific** — include:
   - App version (`Profile → About`)
   - Android version + device model
   - Exact steps to reproduce
   - Screenshots / video
   - Logcat (if possible)

---

## 💡 Suggesting Features

We love new ideas! Use the [**feature request template**](../../issues/new?template=feature_request.yml).

A good feature request includes:
- **Problem** — what pain point are you solving?
- **Solution** — how should it work?
- **Alternatives** — what did you consider?
- **Context** — screenshots, mockups, examples

---

## ⚠️ Please Don't

- ❌ Open issues for **outdated versions** — update first
- ❌ Post **duplicate** issues — search first
- ❌ Share **personal info** or order IDs publicly
- ❌ Ask for **ETA** on features without context

---

## 🔐 Security Issues

**Do not** report security vulnerabilities publicly.  
Email us at: **security@mystore.example.com**

---

Thank you for helping make MyStore better! 🙏
